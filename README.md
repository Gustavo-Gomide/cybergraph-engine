# CyberGraph Engine

Teoria dos Grafos aplicada à Segurança da Informação: Dijkstra (heap + parada antecipada), Bellman-Ford e Floyd-Warshall sobre caminhos de ataque, cenários de mitigação A–E, laboratório 2D passo a passo e ecossistema 3D concorrente (Three.js).

Abra `index.html` no navegador ou acesse via GitHub Pages.
